# Garden journal and daily puzzle

The former reserved Gartenfreund navigation slot is now Gartenbuch. It combines normal catalogue totals/completed gardens with newly measured active puzzle time, local play days, unique normal puzzle IDs solved without hints, daily completions, weekly active-day marks, bookmarks and cosmetics. There is no punitive streak, ranking, extra currency or new puzzle lock.

Statistics begin with this version; historical time, days and hint-free attempts cannot be reconstructed from the ad counters, which reset after ads. Normal solved IDs continue to supply existing progress. Time is hooked into the same active clock as gameplay, excluding prewarm, menus, dialogs, ads, background, paused frames and finished puzzles. Local-midnight intervals are split; single delayed clock gaps are capped at60sec for the journal. Replays update best time/no-hint evidence without duplicating unique counts. A successful charged or unlimited developer hint marks that attempt as assisted. A new/reset attempt starts a new no-hint attempt. Completing a normal bookmarked puzzle removes its bookmark. Manual bookmark removal never resets progress.

Daily rotation v1 is pinned in public/daily-puzzles.js:833 existing exactly checked catalogue IDs, selected for16-42cells and provisional score35-220, deterministically shuffled once. Do not reorder this manifest when reordering the catalogue. The local calendar date indexes this rotation; same date/version gives the same puzzle offline. This is a curated rotation from the existing catalogue, not newly generated daily-exclusive geometry. Future/invalid dates resolve to today. The URL fixes the chosen day during an overnight attempt. Daily progress uses its own date-specific keys and never advances/overwrites normal catalogue progress or current level. Hint budgets/ad state are separate from normal gameplay; daily exit returns to the home screen without an interstitial.

Persistence: nurbi-journey-v1 (preview: nurbi-journey-preview-v1) stores activeMs/days/normal solved evidence/daily results/bookmarked IDs. Existing normal done/current keys unchanged. New game stats and bookmarks are isolated in preview mode. Daily game state uses nurbi-daily-YYYY-MM-DD-* (preview has separate prefix); ad state uses slink-economy-daily-v1 or preview variant.

Four approved Nurbi palettes: Aprikose initially; Lavendel after1completed garden, Lagune after3, Koralle after6. Menu backgrounds: Sand initially, Ruhiges Orange after1; Sonnenorange belongs exclusively to gameplay. The journal applies palettes to game and home while retaining sizes/enabled state; a warm game frame gets a same-origin cosmetics message. The actual model preview reuses the home renderer/model, caches at most four images and adds no WebGL context. Existing developer settings remain for testing and previously selected styles are not forcibly removed.
